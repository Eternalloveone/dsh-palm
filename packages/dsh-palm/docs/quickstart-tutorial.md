# dsh-palm 上手教程：30 秒把 dsh 装进手机口袋

> 适用：已在本机跑起 [dsh](https://github.com/deepseek-ai/deepseek-harness) Web GUI 的用户。
> 本教程与 [remote-access-guide.md](remote-access-guide.md) 互补——那边是公网隧道/服务器的完整手册，这里是**从零到「手机上完成一次对话 + 配好通知」**的最短路径。

## 这是什么

dsh-palm 是一个独立的手机端界面（`/m/`），不是桌面 GUI 的缩小版：

- 手机浏览器打开就是原生触屏体验，零横向滚动
- 断网时消息进离线队列，恢复后自动补发
- 任务完成、长回复结束会推送通知到手机
- 可以查看/审批/回复，但不是深度工作终端——复杂配置留在桌面端

## 第一步：安装（一条命令）

```sh
dsh plugin --profile web add @eternalloveone/dsh-palm
```

然后重启 dsh（桌面侧边栏应出现手机图标 🔌）。

## 第二步：让手机能连到电脑（30 秒方案）

点侧边栏手机图标打开配对面板，选 **同 Wi-Fi（局域网）**：

1. 手机连同一个 Wi-Fi
2. 面板右上角打开「配置」→ 填入面板建议的局域网地址（形如 `http://192.168.x.x:3080`）
3. 保存时面板会先探测这个地址能不能通

> 不在同一局域网？配对面板会自动检测你机器上的隧道：装了 Tailscale 就一键填入 tailnet 域名（约 5 分钟）；已有 frp/Cloudflare Tunnel 就粘贴隧道地址（约 1 分钟，面板会先探测可达性）。完整拓扑与排错见 [remote-access-guide.md](remote-access-guide.md)。

## 第三步：配对（10 秒）

面板显示二维码和 6 位配对码：

- 手机浏览器打开面板给的地址 → 扫二维码
- 或者扫码不便时，在手机上直接输入 6 位数字码

配对码一次性有效、10 分钟过期。配对成功的设备会一直保持信任，直到你在电脑端吊销。

## 现在你能做什么

- **看进度**：任务清单（todo）和后台任务在聊天框上方一条状态条里实时滚动
- **读长回复**：流式渲染 + 思维链折叠，弱网也不卡
- **回复/审批**：消息照常发送；插件的审批请求、提问会在手机上实时弹出
- **控制**：切换模型、发命令（`+` 菜单）、删会话、装插件
- **查用量**：设置 → 用量卡片，每个提供商一行（余额/配额），按需刷新

## 第四步：把通知配好（杀手锏，约 3 分钟）

dsh-palm 最有价值的是「任务跑完时手机响一下」。三层通道，按你的使用方式选：

| 场景 | 用什么 | 配置 |
|---|---|---|
| App 开着（前台/后台） | L1 应用内通知 | 无需配置，允许通知权限即可 |
| App 关了但浏览器在 | L2 Web Push | 设置页打开「Web Push」开关 |
| 浏览器也关了 | L3 Server酱/Bark/Telegram | 见下方 |

**国内用户建议直接配 L3 的 Server酱**（微信里收通知）：

1. 打开 [sct.ftqq.com](https://sct.ftqq.com)，微信扫码登录，复制 SendKey（`SCT…`）
2. 手机端 设置 → 通知 → Server酱 → 粘贴 SendKey
3. 点「发送测试」——几秒后微信应该收到一条测试推送

> 为什么默认推荐 Server酱：Web Push（L2）依赖 Google FCM，国内网络经常连不上；部分国产 ROM（OPPO/vivo 实测）即使有 GMS 也会拦截推送。L3 走你自己的 webhook，国内稳定直达。

通知触发规则（可调）：后台任务进入完成/失败状态立即通知；单次回复超过阈值（默认 30 秒，可调）完成时通知。同一会话有冷却（默认 2 分钟）防轰炸。

## 常见问题

| 现象 | 原因 | 解决 |
|---|---|---|
| 手机打不开面板给的地址 | 防火墙/端口 | 允许 3080 端口入站；面板「配置」里点保存试试探测 |
| 配对后手机一直转圈回到配对页 | 设备被吊销或服务重启过 | 电脑端面板重新扫码配对 |
| 通知测试按钮没反应 | L3 通道未配置或 SendKey 错 | 检查设置页通道状态是否为「已配置」 |
| OPPO/vivo/小米收不到 Web Push | ROM 拦截 FCM | 改用 L3（Server酱/Bark/Telegram） |
| iOS 收不到 Web Push | Safari 限制 | 需「添加到主屏幕」安装为 PWA（iOS 16.4+），或用 Bark |

- 手机端：设置 → **反馈与建议**（直达 GitHub Issues）
