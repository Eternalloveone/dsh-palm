# 手机端样式表（W1-3 起）

这里是手机端样式的**真源**。`../mobile-styles.ts` 是生成物，不要手改。

## 改样式

1. 在 `*.css` 里改（按区块找文件，见下表）。
2. 跑 `pnpm gen:css`（`pnpm build` 也会先跑一遍）。
3. `pnpm test` 里有一条 `mobile-styles.freshness.test.ts`：忘了第 2 步会红。

## 为什么是「字符串拼接」而不是 CSS Modules

手机端页面不带构建期 CSS 管线：样式在构建期被编译成 `lib/mobile/app.css` 一个文件，
由页面 `<link>` 引入（`scripts/build-css.mjs`）。所以这里保持纯文本、按文件名排序拼接，
不引入 `@import` 或模块作用域——顺序即层叠顺序，改顺序就是改优先级。

## 文件顺序 = 层叠顺序

|---|---|

| 030–050 | 头部 / 图标按钮 / 快捷操作 |
| 060–090 | 列表 / 卡片 / 滑动删除 / 新建卡 |
| 100 | 设置页 |
| 110–130 | 空态与错误 / 崩溃页 / 骨架屏 |
| 140 | 按钮 |
| 150–180 | 聊天 / 代码块 / diff / 文件链接 |
| 190 | 消息折叠区（深度思考 / 工具） |
| 200–220 | 回合状态 / 运行条 / 后台任务 |
| 230–260 | 审批 / 输入栏药丸 / 快速选择器 / 输入栏 |
| 270 | 长按菜单 |
| 280–320 | 浮层：sheet / 预览 / 灯箱 / 对话框 / toast |
| 330–350 | 配对 / 目录浏览 / 插件市场 |
| 360–380 | 减少动效 / v2.1 增量 / 正文内思考块 |
| 390–420 | 运行总览 / 回合定位条 / 目标条 |

## token 不在这里

调色板与结构 token（层级、字体、圆角、间距、字阶）在 `../design/tokens.ts`，
由 `designTokensCss()` 生成三段主题 CSS。**不要在组件样式里手写 `--var` 定义**，
只引用。
