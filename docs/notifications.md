# 通知怎么配

手机端的目标就一句话：**任务跑完、或者我要的长回复写完了，手机能响一下。** 不管 App 开着、关着，还是浏览器都退了。

## 一次判断，三条通道

宿主侧有一个通知引擎盯住共享事件流，**只判断一次**，然后把同一个决定发给三条通道：

| 层 | 通道 | 什么时候能到 | 需要什么 |
|---|---|---|---|
| L1 | 应用内系统通知（SSE） | App 还活着（前台或后台） | 手机授权通知权限 |
| L2 | Web Push（VAPID） | App 关了、浏览器还在 | 装成 PWA；密钥宿主自动生成 |
| L3 | WxPusher / 服务器酱 / Bark / Telegram | App 关了、浏览器也没了 | 各渠道的 token / key |

## 什么事件会触发

- **任务结束**：后台任务从 `running` 变 `completed` / `failed`，立即发
- **长回复**：一轮回复耗时超过阈值（默认 30 秒）才发；同一会话有冷却（默认 2 分钟），避免一长串回复连环响
- 被中断的、报错的回合**不发**

这三类（计划完成 / 后台任务 / 长回复）在设置页各有独立开关，默认对后两类保持安静。

## 配置步骤

1. 手机 → 设置 → **通知**
2. 弹权限时点允许
3. 调**时长阈值**（多久算长回复）和**冷却**（同会话隔多久）
4. 想 App 关着也收：打开 **Web Push** 开关，让当前浏览器订阅
5. 想微信 / iOS 收：配 **L3**
   - **WxPusher**：去 [WxPusher 文档](https://wxpusher.zjiecode.com/docs/#/?id=spt) 扫码拿 `SPT…` token，粘进来。免费、国内直达，主推
   - **服务器酱**：在 [sct.ftqq.com](https://sct.ftqq.com) 微信扫码，复制 `SCT…` SendKey
   - **Bark**：装 Bark App（iOS），复制设备 key
   - **Telegram**：找 @BotFather 建机器人，拿 bot token 和你的 chat id
6. 点**发送测试**，会推一条合成事件走通 L3

## 收不到怎么办

按这个顺序排，基本三步定位：

| 现象 | 结论 | 动作 |
|---|---|---|
| 测试按钮成功、真实任务不响 | 阈值或冷却挡了 | 把时长阈值调低，或等冷却结束 |
| 测试按钮也失败 | L3 凭据无效 | 该渠道会显示"已配置 / 未配置"，重填 token |
| App 开着能收、关了就没了 | L2 没订阅或浏览器被杀 | 装成 PWA，重新打开 Web Push 开关；安卓部分 ROM 会拦 FCM |
| iOS 完全收不到 | 没装到主屏 | iOS 16.4+ 必须"添加到主屏幕"才有 Web Push |
| 锁屏只剩"有新消息" | 打开了隐私模式 | 关掉锁屏隐私开关即显示会话标题 |

## 已知限制

- L1 要求页面还活着；锁屏久了或系统杀掉浏览器就断了
- L2 要求浏览器进程在；OPPO / vivo / 小米 / 华为部分机型即使有 Google 服务也会拦 FCM，走 L3
- 国内网络到 FCM 可能不通，需要 `DSH_PALM_PUSH_PROXY` 或 `HTTPS_PROXY`
- 设置页的测试按钮只测 L3，L2 要靠真实任务验证
- 撤销/停用设备会同步清掉它的 Web Push 订阅（不会继续收到审批卡）
