## 二、结论

1. **前 5 个字段占了大部分引用**——它们是跨域共享的核心（依赖注入、代理、日志、预算），
   应当先固化成 `api/api-deps.ts` 的接口，处理器搬出去时只依赖这个接口。
2. **引用 ≤2 次的字段**基本是单域独占，随处理器一起搬走即可，不需要进共享接口。
3. 搬移单位 = **一个域的处理器 + 它独占的字段 + 它独占的局部函数**，一起进 `api/<域>.ts`。
