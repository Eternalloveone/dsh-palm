实现要点

项做法为什么
轨道只铺这次要经过的那几格（3、4、5、6、7）常驻 0-9 会让 DOM 文本变成 0123456789，复制/读屏/断言全错
收回滚完 480ms + 60ms 后塌回一格静止时与普通文字等价，也不占 will-change
方向永远朝上；9 → 0 也是朝上（接第一圈）odometer 的物理直觉，不会来回摆
位数key 从个位往左编9 → 10 只滚个位、冒出新十位，不会整串一起滚
无障碍滚轮 aria-hidden，读屏读 aria-label否则会念成一串数字
减弱动效直接落到新数字组件内判断 + CSS 里 transition: none 双保险
