# 手机端真机验收 SOP（自动化测不到的那部分）

> 自动化能证明的：DOM 结构、几何尺寸、状态机一致性、渲染压测、场景旅程、性能预算、视觉回归。
> 自动化**测不到**的：浏览器不实现的系统能力（输入法组合、相机、PWA 安装、Web Push、震动）
> 与真机手感。这份清单就是那部分的固定动作，**每次发版前照着做一遍**，五分钟。

## 一、输入法（中文/英文/符号）

| # | 动作 | 期望 | 已知坑 |
|---|---|---|---|
| 1 | 拼音输入「zhongwen」，**不选词**直接按回车 | 不发送；输入框内容保留 | 组合态回车被当成发送（自动化只能模拟 composition 事件，真机差异要人眼看） |
| 2 | 选词后再按回车 | 正常发送 | — |
| 3 | 英文输入下按 Shift+Enter | 换行，不发送 | 部分输入法把 Shift+Enter 也吃掉 |
| 4 | 语音输入一小段中文 | 文字落到输入框、标点正常 | 语音输入走 composition，可能触发 1 的坑 |
| 5 | 输入法键盘弹出后看输入框 | 输入框不被键盘遮住，列表随之上移 | iOS Safari 与 Chrome 的 `visualViewport` 行为不同 |

## 二、相机 / 相册 / 文件

| # | 动作 | 期望 |
|---|---|---|
| 1 | 点「＋」→ 拍照 | 相机打开；拍完出现附件芯片 |
| 2 | 从相册选 3 张图 | 三张芯片都在；缩略图不是空白 |
| 3 | 选一个 50 MB 文件 | 有上传进度或"上传中"状态，不卡死界面 |
| 4 | 上传中把 app 切后台 10 秒再回来 | 上传继续或明确失败可重试，不留半死状态 |
| 5 | 发送带附件的一条消息 | 消息里能看到附件，断开重进仍在 |

## 三、PWA（添加到主屏）

| # | 动作 | 期望 |
|---|---|---|
| 1 | 浏览器菜单「添加到主屏幕」 | 图标、名称正确（不要出现默认字母图标） |
| 2 | 从主屏图标冷启动 | 5 秒内出会话列表（冷启动无缓存） |
| 3 | 冷启动后直接进一个会话 | 15 秒内出正文；不白屏、不永远骨架 |
| 4 | 系统设置里清掉该 PWA 的网站数据，再冷启动 | 仍能正常加载（等价于换设备重装） |
| 5 | 从一个会话切到别的 app 再切回 | 不重画、过程条还在（这是场景 `background-return` 的真机版） |

## 四、通知 / 推送 / 震动

| # | 动作 | 期望 |
|---|---|---|
| 1 | 设置页看「通知」这一行 | 显示真实授权状态（未授权/已授权），不是永远"未授权" |
| 2 | 点它 → 系统弹权限框 → 允许 | 回来这一行变「已授权」 |
| 3 | 拒绝权限后再点 | 有明确指引（去系统设置开），不静默失败 |
| 4 | 让一个长任务跑完（手机上不看着） | 收到完成通知（若已授权且宿主支持推送） |
| 5 | 设置页打开「通知震动」 | 完成任务时手机震动一次；关掉后不震 |

## 五、手感与布局（人眼判断）

| # | 动作 | 期望 |
|---|---|---|
| 1 | 长会话快速上滑/下滑 | 跟手，不卡顿（性能基线：滚动 ≥40fps 已自动守） |
| 2 | 横屏看一下聊天页 | 布局不炸、输入框不被裁 |
| 3 | 系统字号调到最大 | 文字不被裁、按钮不变形 |
| 4 | 侧滑返回 / 系统返回键 | 从会话回列表，不误退出整个 PWA |
| 5 | 深色 ↔ 浅色切换 | 立刻生效；刷新后保持（场景 `settings-apply-instantly` 的真机版） |

## 六、发版前必须跑的三条命令

```powershell
cd dsh-source/dsh-palm/packages/dsh-palm
pnpm verify --profile release      # 16 步：CI + 只读场景 + 渲染审计 + 压测 + 验收 SOP + 性能 + 视觉 + 手工场景
# 只想单独复跑"会发消息"的那 9 个旅程：
node tools/mobile-scenarios/run.mjs --manual --create-test-session
```

`verify --profile release` 里已经包含手工场景那一步；单跑第二条是为了快速定位。
两者都会自己建一条专用测试会话（标题带 `[palm-e2e]`）、跑完自动归档，不会碰你自己的会话。

## 七、发现问题怎么报

带上三样，定位速度差十倍：

1. **哪一页**（列表 / 聊天 / 运行中 / 设置）
2. **什么动作之后**（刚进会话？切后台回来？发完消息？）
3. **会话标题前几个字**（我用它去 `dsh-palm-errors/` 找现场快照）
