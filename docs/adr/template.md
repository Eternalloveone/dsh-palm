# NNNN · 一句话说清这个决定

- **状态**：提议 / 已接受 / 已废弃 / 被 NNNN 取代
- **日期**：YYYY-MM-DD
- **影响范围**：哪几个包/目录
- **相关**：链接到代码、测试、其他 ADR

## 背景（Context）

当时面对什么情况。**写事实，不写情绪**：多少行代码、几个模块各写各的、真机现象是什么、
哪次线上故障暴露的。有数字就给数字——"11 个模块各写各的缓存"比"缓存很乱"有用一百倍。

## 决定（Decision）

选了哪条路，具体到能照着做：哪个文件放哪、什么被禁止、门禁怎么判。

## 代价（Consequences）

**这一节不许写成好处列表。** 至少写清：

- 什么变麻烦了
- 什么被放弃了（以及放弃后可能的后果）
- 什么情况下这个决定会变得不成立（触发复查的条件）

## 备选方案（Alternatives）

考虑过但没选的，各自为什么不选。**如果当时只有一个方案，说明没想清楚**。
