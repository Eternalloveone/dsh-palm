# 能力清单

README 只放 6 条。这里是完整的一张表，按"你什么时候会用到"分组。

## 一、看进度

| 能力 | 说明 |
|---|---|
| 运行总览 | 一屏看完所有工作区正在跑什么：当前动作、第几步、已跑多久，点卡片直接进会话 |
| 运行中状态条 | 待办计划 + 后台任务合并成工具条上方一条，实时刷新 |
| 过程条 | 一轮对话折叠成一条"现在在干什么"，展开是完整时间线（思考 / 工具 / 差异） |
| 刚结束 | 结束的会话不消失，落进「刚结束」，带结果、耗时和一句话总结 |
| 回合导航 | 右下角悬浮条显示「当前 / 总轮」，点开看全部回合，横向拖动可快速跳转 |
| 子代理 | 一轮里派出的子代理列出来，点进去只读看它的任务、每一步和回答 |

## 二、发消息

| 能力 | 说明 |
|---|---|
| 中文输入 | 输入法组词期间不会把半截拼音发出去 |
| 图片 | 拍照或相册，手机端压缩后再上传，超限会提示而不是静默丢 |
| 文件 | 一次 5 个、每个 20 MB，走宿主附件服务，消息本身只带回执 |
| 宿主文件 | 手机选不到文件时，可以直接浏览这台电脑的目录，插入 `@绝对路径` |
| 语音 | 浏览器内录音（60 秒自动结束），可配多家转写服务，边录边出字幕 |
| 斜杠命令 | `/` 面板选命令插入蓝色芯片，只锁命令词，参数仍可改 |
| 待发队列 | 一轮在跑时发的消息进宿主队列，工具条上方显示，可改、可删、可打断 |
| 目标条 | 桌面端的 goal 条同步到手机，可暂停 / 继续 / 展开看全文 |

## 三、审批与回答

- 工具审批实时推送到手机，就地同意或拒绝，答案绑定发起设备（不会被别的设备抢答）
- 提问面板同上，选项与自由文本都支持
- 权限模式与预设在设置里可切；复杂预设建议回桌面改

## 四、管会话

| 能力 | 说明 |
|---|---|
| 会话抽屉 | 按工作区分组，显示真实项目名、完整时间；首屏只画 20 行，滑到底再补 |
| 会话动作 | 长按出底部面板：置顶 / 重命名 / 删除（二次确认） |
| 全局搜索 | 首页搜索跨所有工作区，按工作区分组；点命中直接跳到那条消息并高亮一次 |
| 会话内搜索 | 列表页搜索收窄到当前工作区；上下逐个跳，到边界才翻页 |
| 交付卡 | 一轮产出的文件与改动收进一张卡，最近一轮默认展开 |
| 用量 | 抽屉「用量」行显示当前模型那家的真实数字（本周已用 33% / 余额 ¥23 / 已用 $0.49） |

## 五、通知

三种到达方式：应用内系统通知、Web Push、第三方渠道（WxPusher / 服务器酱 / Bark / Telegram）。详见 [notifications.md](notifications.md)。

## 六、外观

| 能力 | 说明 |
|---|---|
| 皮肤 | 24 套（含液态玻璃、赛博夜、龙裔、初音、我的世界、XP、深海流淌等），点抽屉头像即换 |
| 壁纸 | 可换本机图片做背景，自动压缩与明暗适配 |
| 图标贴图 | 每套皮肤带自己的图标笔画（不是换色） |
| 字号与密度 | 字号缩放、列表密度、行号、自动滚动 |
| 主题同步 | 桌面端明暗偏好同步到手机 |

## 七、可靠性与诊断

| 能力 | 说明 |
|---|---|
| 弱网 | SSE 断流后自动降级轮询，恢复即切回；半死连接有看门狗，不会冻结 3 分钟 |
| 实时自愈 | 三条不变量：贴底必跟尾、落后 24 帧即补拉、闸门超时兜底（详见 [plan-live-render-self-heal](plan-live-render-self-heal.md)） |
| 离线 | 断网时提示词进 IndexedDB 队列，回网自动发 |
| 不白屏 | 渲染出错给可读错误页 + 重试；窗口错误、未捕获异常、资源加载失败都进环形缓冲 |
| 可上报 | 崩溃报告可转发到你配的渠道（手机自己崩了没法自救） |
| 缓存 | 申请持久化存储，长期后台不会无声丢历史 |
| 卡顿可分辨 | 区分"应用卡"和"系统冻结"，分别记 Long Task 与 `suspension.hiddenMs` |
