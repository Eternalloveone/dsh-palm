# 手机端 UI 定版规范（v1）

> 定版依据：`shot-final2.png`（18 屏全量图）。本文件是实现的唯一依据，样式数字与它不一致时以本文件为准。

---

## 一、三条主线

1. **对话为主**：产物次之（一条入口 → 独立页），工作区最后（设置里）。
2. **零手势**：全部点击 + 系统返回（页面栈）。不做抽屉、不做底部弹层、不注册任何自定义滑动。
3. **每轮一张结论卡**：结论在上、过程折叠、动作在卡里、数字必须真实。

---

## 二、设计令牌（唯一来源）

```css
/* 字号：只有 5 档 */
--t-s: 12px;   /* 辅助：时间、标签、脚注 */
--t-m: 14px;   /* 正文：消息、按钮、列表标题 */
--t-l: 17px;   /* 标题：页面标题、结论句 */
--t-xl: 22px;  /* 页面大标题 */
--t-2xl: 28px; /* 强调数字（KPI） */

/* 行高：只有 2 档 */
--lh-body: 1.5; --lh-head: 1.3;

/* 字重：只有 2 档（中文不用 500，会被合成加粗） */
--w-normal: 400; --w-bold: 600;

/* 间距：4 的倍数 */
--s1:4px; --s2:8px; --s3:12px; --s4:16px; --s5:20px; --s6:24px;

/* 圆角：3 档 */
--r-s:8px; --r-m:12px; --r-l:18px;

/* 文字灰：3 档 */
--fg:#f4f4f8; --fg-2:#a6a6b6; --fg-3:#70707f;

/* 表面：3 档实色（禁用半透明白，会导致灰度漂移） */
--bg:#101015;      /* 页面底 */
--sur-1:#15151c;   /* 卡片、输入框、chip */
--sur-2:#1c1c25;   /* 浮层、选中、审批卡 */

/* 边框与物性 */
--line: rgba(255,255,255,.07);
--hi:  inset 0 1px 0 rgba(255,255,255,.06);   /* 顶部内高光：让卡片像实物 */
--sh1: 0 1px 2px rgba(0,0,0,.45);
--sh2: 0 6px 20px rgba(0,0,0,.55);

/* 语义色 */
--accent:#7c8cff; --ok:#3ddc84; --warn:#e0a52c; --danger:#ff6b81;
```

## 三、组件规范

### 3.1 卡片（三级）

| 级别 | 底色 | 阴影 | 用在哪 |
|---|---|---|---|
| 内容卡 | `--sur-1` | `--hi, --sh1` | 结论卡、产物卡 |
| 浮层卡 | `--sur-2` | `--hi, --sh2` | 审批、选中项 |
| 列表卡 | 透明 | 无（只用分隔线） | 密集列表 |

统一：`border:1px solid var(--line); border-radius:var(--r-l); padding:16px`。
语义色只作用于**边框**，不给整卡染色（完成=绿边，审批=琥珀边）。

### 3.2 按钮（四种 × 六态）

高度 **44px**，圆角 `--r-m`，字号 `--t-m`/`--w-bold`，水平内边距 18px。

| 类型 | 视觉 | 用途 |
|---|---|---|
| 主 | `linear-gradient(180deg,#8b98ff,#6f7ff2)` + 彩色落影 | 继续、应用、重试 |
| 次 | `--sur-2` + 描边 | 取消、拒绝、看看 |
| 成功 | 绿 15% 底 + 绿描边 | 允许删除 |
| 危险 | 红 13% 底 + 红描边 | 拒绝、删除 |

状态：`hover` 亮度 +4%；`active` `translateY(1px)` + 亮度 −6%；`disabled` opacity .36；`focus-visible` 2px 外描边 `--accent`。

### 3.3 其它

| 组件 | 规格 |
|---|---|
| 输入框 | 高 52px，圆角 `--r-l`，`--sur-1` + 内高光 |
| chip（模型/批准/上下文） | 高 30px，圆角 `--r-s`，`--sur-1`；危险项用琥珀 tint |
| 列表行 | `padding:12px 16px`，`border-bottom:1px solid --line` |
| 标签 | 高 20px，圆角 6px，tint 底（琥珀/绿/靛蓝） |
| 图标 | **16px 线性 SVG，描边 1.75，currentColor**；禁止 emoji 与字符混排 |
| 进度条 | 高 6px，圆角 4px，底 `rgba(255,255,255,.07)` |

## 四、结论卡（四态一骨架）

```
┌ 标签（结论 / 要你决定 / 正在做 / 没做成）
│ 结论句（17px 加粗，必须第一句）
│ 补充一句（14px，次灰）
│ [交付物条 / 影响范围条]
│ [动作 1][动作 2]（最多 3 个，其余进 ⋯）
└ 脚注（思考秒数 · 工具次数 · token）
```

**四条硬规则**：每轮只出现一次；第一句是结论；数字真实可验证（行数/条数/秒数，禁编百分比）；动作只放最可能的 2–3 个。

## 六、皮肤（与令牌的关系）

皮肤 = **同一份组件样式 + 不同令牌值**，不改结构、不改类名。

| 皮肤 | 底 | 表面 | 强调 | 圆角 |
|---|---|---|---|---|
| 石墨（默认） | `#101015` | `#15151c` | `#7c8cff` | 8/12/18 |
| 纸 | `#faf8f4` | `#fff` | `#8a5a2b` | 6/10/14 |
| 夜航 | `#080c14` | `#0f1520` | `#22d3ee` | 10/14/20 |

实现：`html[data-skin="graphite|paper|nocturne"]` 切变量，零 JS 计算样式。
