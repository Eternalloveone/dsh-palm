# dsh-palm GitHub 首页视觉方案（2026-11-12）

> 目标：让第一次点进仓库的人在 **10 秒内**看懂三件事——这是手机的 dsh、它能看进度/收结果/回消息、30 秒能接上。
> 结论：**1 张 4 拍循环 GIF + 6 张静态 + 1 张皮肤九宫格**，全部 2x、图内不写字、中英共用一套图。

## 1. 参考与取舍

| 参考项目 | 借什么 | 落到 dsh-palm |
|---|---|---|
| shadcn/ui | 首屏一张主图，下面密排功能图；克制、无花字 | 主图只放手机屏幕，不加爆炸贴纸 |
| Excalidraw / tldraw | 一张 GIF 只演**一个**交互闭环，不在图里堆功能 | 4 拍：通知 → 打开 → 看过程 → 回一句 |
| Immich / Cal.com | 2–3 列功能卡，每卡一图一句动词短句 | 2×3 网格，每格 ≤14 字 |
| Raycast / Warp | 深色底 + 设备框 + 柔和渐变，GIF ≤5 MB | 石墨深色、圆角屏、浅渐变底 |
| LobeChat / Chatbox | 徽章、双语、功能卡，中文项目也能好看 | 中英 README 共用图，文案各自本地化 |

**不学的**：编号标注线（会过期）、大量截图轮播（没人翻）、带字幕的 GIF（中英要两套）。

## 2. Hero GIF 分镜（10–12 秒，循环）

| 时间 | 画面 | 动作 | README 旁白（不进图） |
|---|---|---|---|
| 0–3s | 锁屏通知：`dsh-palm · 任务完成`，副标题 `3 个交付物 · 12 分 04 秒` | 点通知，进会话 | 它跑完会叫你 |
| 3–6s | 聊天页，过程卡展开：`运行命令 pnpm test · 第 7 步 · 已跑 12:04` | 上滑看过程 | 不用回电脑，过程就在手里 |
| 6–9s | 回合报告：交付物列表 + diff 卡 | 点 `接受`，卡片变已接受 | 结果能直接动手 |
| 9–12s | 输入框打字、发送，消息入队/发出 | 回到顶部，与首帧交叉淡出 | 顺手回一句，继续下一轮 |

- 数据全部是 demo（工作区 `demo`，会话标题「重构设置页」），不出现真实项目名/路径。
- 录制 30fps、输出 12fps；首尾同帧，循环不跳。
- 不加鼠标光标、不加点击涟漪（手机 UI 用「按下态」表达）。

## 5. 规格（硬指标）

| 项 | 规格 | 理由 |
|---|---|---|
| GIF | 540×1168，12 fps，10–12 s，**≤4 MB** | GitHub 自动播放；>5 MB 首屏会卡 |
| 静态图 | 780×1688（2x），**≤300 KB/张** | 390 宽 1x 在 Retina 上发虚 |
| 皮肤图 | 1200×800 或 780×1560（2×3） | 六台并排，宽图更省纵向空间 |
| 社交预览 | 1280×640（可选） | GitHub repo social preview |
| 格式 | PNG（pngquant）/ GIF（gifski 或 ffmpeg palettegen） | 体积与色带平衡 |
| 内容 | 无真实项目名、无本地路径、无 token | 仓库是 public；hygiene 门禁会拦 |

## 6. 制作步骤（可复用现有工具）

| 步骤 | 做什么 | 产出 | 估时 |
|---|---|---|---|
| 1 | 固定 demo 数据：工作区 `demo`、3 个会话、1 个跑到第 7 步的回合、1 个带报告+diff 的收工回合 | `tools/readme/demo-fixture.mjs` | 1h |
| 2 | Playwright 2x 录屏 + 四拍暂停点；ffmpeg 调色板转 GIF，压到 4 MB 内 | `hero.gif` + `tools/readme/record-hero.mjs` | 2h |
| 3 | 六个状态逐一截 2x 图；皮肤页 2×3 拼图 | `01–06.png` + `tools/readme/stills.mjs` | 1.5h |
| 4 | 体积/尺寸门禁 + 双语 alt 文案；替换 README 表格 | `tools/readme/check-assets.mjs` + 两份 README | 1h |
| 5 | 旧图归档/删除，CI 不跑录屏（只校验已有资产尺寸） | 提交 | 0.5h |

## 7. 风险

- **GIF 超 4 MB**：先降帧率（12→10）再降宽（540→480），不要先减时长——四拍少一拍故事就断了。
- **假数据穿帮**：截图前用 `demo` 工作区和编造会话；项目名一律 `proj-a / proj-b`。
- **图内写字**：一旦写了中文，英文 README 就得再来一套；坚持图内零文案。
- **首屏过长**：6 张是上限；第 7 张起放「更多截图」链接，别让 Quick start 掉到三屏外。
