不要“路”的三种做法

共同点：没有轨道、没有虚线、没有填充条。进度由角色或它的附属物表达。

A · 能量环宠物居中，环闭合即完成（Finch / Apple Watch 的路子）推荐

环只有 2px 弧线、绕在宠物身上，不占横向空间 → 右侧文字可以完整显示。
未知总量时环变成缓慢旋转的虚线段（不是填充），依然没有“路”。

B · 气泡串每完成一步点亮一颗，当前那颗在跳（Tamagotchi 式计数）

7 颗 = 总步数，实心 = 做完，跳动 = 正在做。没有底轨，所以不会读成“跑道”。
步数未知时只显示一颗跳动，不假装有 7 颗。

C · 纯角色 + 计数最克制：只有宠物、「3 / 7」和一排小方块

信息最少，最不容易看错。缺点是“还剩多少”不明显，得靠数字读。
适合放在会话列表那种很小的位置。
